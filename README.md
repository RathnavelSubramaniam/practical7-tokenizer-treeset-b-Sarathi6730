# 2024_AJP_PRACTICAL7-A
TOKENIZER TREESET
Step 1: Create a Scanner object to read input from the user.
Step 2: Prompt the user to enter a line of text.
Step 3: Read the line of text input by the user.
Step 4: Create a TreeSet<String> object named 'tokenSet' to store the tokens.
Step 5: Split the input line into tokens using the split method and whitespace as the
delimiter.
Step 6: Iterate over each token obtained from the split operation and add the current token
to the 'tokenSet'.
Step 7: Print the elements of 'tokenSet', ensuring they are printed in ascending sorted order
automatically.
Step 8: Close the scanner object.
